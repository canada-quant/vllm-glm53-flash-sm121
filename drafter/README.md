## Reproduce a measurement
1. Serve the target with the drafter (x86: the command on the model card; DGX Spark: the launcher in this repo).
2. Run the client against it — it renders the prompts with the target tokenizer (thinking ON), hits `/v1/completions`, and reads acceptance
   from vLLM `/metrics` deltas (mean acceptance length = 1 + accepted / drafts):
```bash
python3 drafter/eval/holdout_client.py --url http://127.0.0.1:8000 --prompts drafter/eval/prompts_holdout_500.jsonl \
  --model-dir /models/glm53-flash-w4a16-mtp --served-name glm53 --limit 500 --concurrency 16 --max-tokens 1024 \
  --out results/<label>.json --label <label>
python3 drafter/eval/holdout_client.py ... --limit 100 --concurrency 1 --out results/<label>-c1.json --label <label>-c1   # single-stream
python3 drafter/eval/holdout_client.py ... --max-tokens 4096 --out results/<label>-mt4096.json --label <label>-mt4096       # deep traces
```
Measure the reference drafter with the same command on the same box before quoting a comparison.

## How they were trained (summary)
Trainer: [Tencent/AngelSpec](https://github.com/Tencent/AngelSpec) (Apache-2.0) with vLLM `extract_hidden_states` workers. Head: DFlash2
(8 Qwen3-style layers, hidden 4096, 32/8 heads, grouped dynamic conv k=2 g=16, top-16 candidate selector rank 256), 9 target taps
[5, 9, 14, 19, 24, 28, 33, 38, 42], block size 8 (K=7), full attention, learnable mask embedding (`mask_embedding.pt`). Data: prompts from
public instruction sets, **every completion regenerated by the target model itself** (thinking ON, ≤ 4,096 tokens) — no third-party model
outputs, no incoai weights or traces anywhere in the training path. Lineage: E (350K samples) → F (+100K fresh, one pass, lr 1e-4 → 1e-5) →
G (+291K fresh real-chat / tool-calling / hard-math / code / STEM prompts, 70K steps). Loss: CE + top-20 KL with tail weighting.
What did not help: weight soups (1 of 7 beat its best member, by noise), low-LR extra epochs on old data (flat), and long-trace top-ups
(12K–30K completions regenerated at a 15K-token cap, 16K training sequences: deep-trace acceptance stayed at 3.47–3.49 for every drafter,
incoai included — a ceiling of the target's long thinking, not a training gap).
